# 📚 DSA-2026 — Data Structures & Algorithms in Java

> A structured collection of algorithm implementations and pattern-based problem solving in Java, organized for interview preparation and skill building.

---

## 📌 Overview

This repository contains clean Java solutions to **Data Structures & Algorithms** problems, covering core patterns used in technical interviews at top tech companies.

---

## 🗂️ Topics Covered

| Category | Topics |
|---|---|
| **Arrays & Strings** | Two pointers, sliding window, prefix sums |
| **Linked Lists** | Reversal, cycle detection, merging |
| **Trees & Graphs** | BFS, DFS, binary search trees |
| **Dynamic Programming** | Memoization, tabulation, classic patterns |
| **Sorting & Searching** | Merge sort, quick sort, binary search |
| **Recursion & Backtracking** | Subsets, permutations, combinations |
| **Stack & Queue** | Monotonic stack, priority queue |

---

## 🛠️ Tech Stack

- **Language:** Java 17
- **Build Tool:** Maven

---

## ⚙️ Getting Started

```bash
# Clone the repo
git clone https://github.com/Raghavaaverineni11/DSA-2026.git
cd DSA-2026

# Build
mvn compile

# Run a specific solution
mvn exec:java -Dexec.mainClass="com.dsa.YourClass"
```
